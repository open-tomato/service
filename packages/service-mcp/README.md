# @open-tomato/service-mcp

Model Context Protocol adapter for @open-tomato/service: server factory, transports and health endpoints.

Part of the [@open-tomato/service](https://github.com/open-tomato/service) stack; the repository README has the overview and examples.

```sh
npm install @open-tomato/service-mcp
```

Node.js 22 or later, or Bun. ESM only. Licensed under Apache-2.0.
