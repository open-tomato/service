# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in any `@open-tomato/service*` package, **do not open a public issue**. Instead, report it privately using GitHub's private vulnerability reporting:

1. Visit the [Security Advisories](https://github.com/open-tomato/service/security/advisories/new) page
2. Click "Report a vulnerability"
3. Provide details about the vulnerability

All vulnerability reports are reviewed and addressed promptly in private before any public disclosure.

## Supported Versions

Nothing is published yet. Once it is, only each package's latest minor release line (`0.x.*` where `x` is the highest released minor) receives security fixes.

When a new minor release is published, the previous minor line enters maintenance mode with no further updates.
